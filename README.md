# WMS: модуль склада и автономные тесты

Этот репозиторий упаковывает неизменённый snapshot `modules.wms` под теми же обычными импортами и запускает 38 существующих случаев декодирования политики и 5 небольших регрессий GS1/Decimal. Ожидаемый объём — 43 тестовых случая.

Для локального запуска:

```powershell
python -m pip install -e ".[test]"
python -m pytest -q tests/test_wms_placement_policy_codec.py tests/test_wms_gs1.py
```

GitHub Actions запускает весь набор и сохраняет JUnit-отчёт как артефакт. Тесты не требуют CRM, `core`, базы данных, секретов или обращения к родительскому checkout.

Проверка ограничена чистыми GS1 и декодером складской политики. Полный geometry-набор из 149 случаев остаётся в ERP. Последний отдельный запуск 19 транзакционных сценариев в ERP остановился по лимиту времени; этот набор из 43 тестов не исправляет и не заменяет его. Пакет не проверяет сервисы, ORM, миграции, транзакции и конкурентность PostgreSQL, интерфейсы Android/ТСД, интеграцию с 1С или готовность к production и выпуску.

Этот репозиторий содержит складской модуль. Изменения ядра ERP, других модулей, миграций, веб-интерфейса и Android-приложения находятся в основном проекте и не входят в эту автономную проверку. Для запуска всей ERP требуется совместимая версия основного проекта.
